## 🧭 What I'm About

I work in the **SAP / ERP world**, where code doesn't live in demos. It runs payroll, invoices, inventory, and decisions that real companies depend on every day.

On the side, I got pulled into **AI**. I built a referee that decides *"goal or no goal"* using **CNN + YOLO**, and it worked. But I realized I could make a model run without fully understanding it.

So I'm doing both, deliberately:

- 🏗️ **Going deep in ABAP and S/4HANA**, to write clean, modern, production-grade code
- 🧠 **Rebuilding my AI foundations from zero, in public**, until I can explain every model I use
- 🔗 **Aiming at the intersection**, where AI meets enterprise systems (think: RAG over ERP documentation, smarter business processes)

> Most people know one of these worlds. I'm aiming to speak both.
